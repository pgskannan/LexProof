LexProof Offline Verifier

This page does not call LexProof. It recomputes SHA-256 hashes in your browser and reads the LexProofRegistry contract on Ethereum Sepolia through a public RPC. You can save this HTML file and open it from disk. Confirming an on-chain anchor still requires a network connection to Sepolia — not to LexProof.

A mismatch means the bundle, the original document, or the on-chain record has been altered.

If you attach the original file, this page SHA-256s its bytes and UTF-8 text and compares them to original_document_hash in the bundle.
